# Правила ИИ-ревью

- Отмечай изменения поведения с конкретным сценарием сбоя. Проверки форматирования и общие советы пропускай.
- Проверяй, что операции чтения и изменения клиентов учитывают мягкое удаление и что ошибки домена сохраняют контракт OpenAPI.
- Проверяй совместимость Liquibase-миграций с уже применёнными changeset и со схемой, которую валидирует JPA.
- При изменениях валютного клиента проверяй направление пары в ключе кэша, TTL и поведение при ошибках. Счётчик внешних обращений должен учитывать повторные попытки и пропускать попадания в кэш.
- Для каждого замечания назови условие сбоя, его последствие и предложи конкретное исправление. Пиши по-русски.
